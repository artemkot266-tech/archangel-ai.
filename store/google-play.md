Всё, что вставлять в Play Console. Копируйте блоки как есть. Актуально на 22.11.2026, версия 0.21.0.

**Файл для загрузки:** `ARCHANGEL_AI-<версия>-google-play.aab` из раздела Releases на GitHub

## 3. Содержание приложения (App content) — ответы

### Целевая аудитория
- Возраст: **18+** (только). Приложение не для детей.

### Возрастной рейтинг (анкета IARC)
- Категория: «Утилиты, инструменты, продуктивность».
- Насилие, секс, ненормативная лексика, наркотики, азартные игры — **нет**.
- Пользователи могут общаться между собой — **нет**. Обмен местоположением с другими — **нет**.
- Покупки в приложении — **нет**. Неограниченный доступ в интернет (браузер) — **нет**.
- Приложение может показывать сгенерированный ИИ текст — **да** (если анкета спрашивает).

### Реклама
- **Нет рекламы.**

### Декларация о финансовых функциях (Financial features)
- Отметьте: **«Моё приложение не предоставляет финансовые услуги»** / или, если требует выбора, —
  **информация о рынке/инвестициях (без проведения сделок)**.
- Не отмечайте «криптобиржа» и «кошелёк»: в версии play сделки на реальные деньги отключены,
  приложение не хранит и не переводит средства.

### Доступ для проверки (App access)
- «Все функции доступны без особого доступа» — **но** для ИИ нужен ключ. Напишите:
  `Для ответов ИИ введите бесплатный ключ Google Gemini (aistudio.google.com/apikey) в Настройки → Мозг. Остальные функции работают без входа.`

### Безопасность данных (Data safety)
- Собирает или передаёт данные? **Да.** Шифрование при передаче — **да** (HTTPS). Удаление по запросу — **да**.
- Аудио → **Голос или звукозаписи**: передаётся (распознавание речи команды), не хранится у разработчика,
  обязательно для голоса, цель — функциональность. Отклик на имя обрабатывается на устройстве (не передаётся).
- Сообщения → **Другие сообщения в приложении** (текст запросов к ИИ): передаётся, функциональность.
- Фото и видео → **Фото**: передаётся ИИ, только если приложили, необязательно.
- Местоположение → **Приблизительное**: передаётся (погода), необязательно.
- Финансовая информация → **Другая финансовая информация** (параметры ордеров демо-счёта): передаётся бирже, необязательно.
- Контакты, календарь: **не собираются** (читаются только на устройстве).
- Аналитика, реклама, продажа данных: **нет**.

### Разрешения и сервисы переднего плана (Foreground service) — декларация
- Тип: **Microphone**.
- Описание:
  `Голосовой помощник откликается на своё имя (как умная колонка). Пользователь сам включает «Режим ожидания → Слушать в фоне» после экрана с раскрытием. Пока режим включён, сервис переднего плана с постоянным уведомлением и кнопкой «Выключить» слушает микрофон и распознаёт только имя помощника на устройстве (офлайн, без записи и передачи). Если остановить сервис, помощник перестанет откликаться на имя в фоне.`
- Влияние на пользователя, если отложить/прервать: `Пользователь произнесёт имя, а помощник не ответит.`
- **Видео (обязательно)** — снимите экран телефона 30–60 секунд и загрузите на YouTube (доступ по ссылке):
  1. Открыть Архангел → Настройки → Режим ожидания → включить «Слушать в фоне».
  2. Показать экран раскрытия «Микрофон в фоне» и нажать «Разрешаю».
  3. Свернуть приложение — показать уведомление «Архангел слушает» в шторке.
  4. Сказать «Архангел, который час» — показать ответ.
  5. Нажать «Выключить» в уведомлении — уведомление пропадает.

### Точные будильники
- В версии play используется только SCHEDULE_EXACT_ALARM (пользователь включает сам) — декларация не нужна.

## 5. Порядок публикации (личный аккаунт)

1. Зарегистрировать аккаунт разработчика ($25, паспорт, карта, 18+), пройти проверку личности.
2. Добавить ключ загрузки в секреты GitHub (`store/upload-key.md`) → дождаться сборки с файлом `.aab`.
3. Создать приложение → заполнить «Содержание приложения» (раздел 3) и страницу (разделы 1, 2, 4).
4. **Закрытое тестирование**: загрузить `.aab`, добавить **12+ тестировщиков** (их Gmail) и держать тест **14 дней**.
5. Запросить доступ к рабочей версии (Production) → ответить на вопросы о тестировании → отправить на проверку.
