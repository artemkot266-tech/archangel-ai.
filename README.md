# ARCHANGEL AI

Личный ИИ-ассистент для Android: голос, управление телефоном, рынок и трейдинг.
Kotlin + Jetpack Compose, без серверов — всё работает на телефоне.

## Установить
1. Откройте **Releases** этого репозитория → последняя сборка → скачайте `ARCHANGEL_AI-x.y.z.apk`.
2. Откройте файл на телефоне, разрешите «Установка из неизвестных источников».
3. Новые версии ставятся поверх старой — данные сохраняются.

## Первый запуск
1. **Настройки → Мозг**: выберите Claude или DeepSeek и вставьте API-ключ.
   - Claude: https://console.anthropic.com → API Keys (оплата отдельно от подписки Claude).
   - DeepSeek: https://platform.deepseek.com → API Keys (дешевле).
2. Разрешите микрофон при первом нажатии на сферу.
3. Для звонков по имени разрешите доступ к контактам (спросит при первом звонке).

## Биржа (Binance)
- Сначала потренируйтесь на **демо-счёте**: войдите в Binance → **Demo Trading** (demo.binance.com) → API Key Management → создайте ключ. Цены реалистичные, деньги ненастоящие.
- Реальный ключ: Binance → Управление API. Права — **только спот-торговля**, **без вывода средств**. Лучше ограничить по IP, если есть возможность.
- Любой ордер исполняется только после вашего подтверждения на экране.
- Разбор ИИ — мнение модели, а не гарантия и не финансовый совет.

## Что умеет голос
| Скажите | Что произойдёт |
|---|---|
| «Позвони маме» | найдёт контакт и попросит подтвердить звонок |
| «Напиши Саше что я опоздаю» | откроет SMS с текстом |
| «Будильник на 7:30», «Таймер на 5 минут» | поставит в «Часах» |
| «Включи фонарик», «Громче» | сразу |
| «Открой Телеграм» | откроет приложение |
| «Маршрут до вокзала» | откроет навигатор |
| «График биткоина», «Курс эфира» | раздел «Рынок» |
| «Купи биткоин на 20 долларов» | ордер с подтверждением |
| Любой вопрос | ответит мозг (Claude / DeepSeek) |

## Устройство проекта
```
app/src/main/java/com/archangel/ai/
  ai/        — запросы к Claude / DeepSeek / OpenAI-совместимым API
  data/      — настройки (зашифрованные ключи), история чата
  phone/     — разбор команд и действия на телефоне
  market/    — Binance: свечи, тикер, баланс, ордера; индикаторы
  voice/     — распознавание и синтез речи
  ui/        — экраны, сфера (AGSL-шейдер), компоненты, тема
```
Сборка: `./gradlew assembleDebug` (JDK 17). На GitHub сборка и тесты запускаются автоматически при каждом коммите.

Журнал изменений — в [CHANGELOG.md](CHANGELOG.md).
