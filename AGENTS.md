# Правила для агента-разработчика ARCHANGEL AI

Этот файл читает автоматический агент перед каждой работой над проектом.
Владелец проекта общается только с телефона (Poco F9 Ultra, HyperOS), ПК нет.
Он не программист: всё объяснять коротко, по-русски, без жаргона.

## Как устроен цикл
1. Агент изучает код, CHANGELOG.md и PROPOSALS.md (что уже предлагалось и чем кончилось).
2. Выбирает 1–3 улучшения (функция, дизайн, стабильность, скорость) — небольших, законченных.
3. Делает их в ветке `proposal/<ГГГГ-ММ-ДД>-<короткое-имя>` от свежего `main`.
4. Пушит ветку. CI сам соберёт тестовый APK и выложит его как pre-release `proposal-N`.
5. Ждёт зелёную сборку (тесты + сборка). Если красная — чинит в той же ветке.
6. Пишет владельцу: что предлагает, зачем, ссылку на тестовый APK, и спрашивает «да / нет / поправить».
7. Только после явного «да» — мёрж в `main`: поднять versionCode/versionName, запись в CHANGELOG.md
   (формат: ➕ Добавлено / ✏️ Изменено / ➖ Удалено), отметка в PROPOSALS.md.
   «Нет» — ветка остаётся, в PROPOSALS.md пометка «отклонено» и причина, больше не предлагать.

Никогда не пушить в `main` без одобрения владельца.

## Технические рамки
- Kotlin 2.0.21, AGP 8.7.3, Compose BOM 2024.12.01, minSdk 26, target/compile 35.
- Локального Android SDK нет: компилятор и тесты — это CI (GitHub Actions). Ошибки читать из
  аннотаций check-run.
- Регулярки для русского текста: `[\p{L}\d_]` вместо `\w`, флаг `(?iu)`.
- Новые голосовые команды — в `CommandParser` + тест в `CommandParserTest`.
- Подпись: `app/keystore/debug.keystore` не трогать (иначе обновления не встанут поверх).

## Дизайн (не ломать)
- Фон — сплошной Obsidian `#0B0B0C`, без зерна, точек, неона, «старого телевизора».
- Шрифты — только Geist / Geist Mono. Никаких декоративных шрифтов.
- Акцент — Ember `#FF5A1F`, текст Bone/Ash/Smoke, тонкие линии Hairline.
- Жидкая металлическая сфера (`ui/core/Orb.kt`, капли + лужа с отражением) — любимая часть владельца.
  Менять только по его прямой просьбе.

## Безопасность (жёстко)
- Не добавлять разрешения, за которые Play Защита блокирует установку: RECEIVE_SMS, READ_SMS,
  NotificationListenerService, AccessibilityService.
- Никаких API-ключей в коде/APK.
- Сделки на бирже — только после подтверждения, по умолчанию демо-счёт; реальные деньги — только кнопкой
  на экране, не голосом. Ключи Binance — без права вывода.
- Звонки и SMS — только с подтверждением.
- Не копировать голос реального актёра.
