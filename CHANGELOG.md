# Журнал изменений ARCHANGEL AI

Формат: что **добавлено**, что **изменено**, что **удалено**. Новые версии — сверху.

## 0.6.0 — 21.11.2026

### Добавлено
- Ярлыки на иконке приложения (долгое нажатие): **«Голос»** — Архангел сразу начинает слушать, **«Рынок»** — открывает графики. Ярлык можно вынести на рабочий стол.

### Изменено
- Приложение открывается в одном экземпляре: повторный запуск из ярлыка не плодит окна.

## 0.5.1 — 21.11.2026

### Исправлено
- Свечение сферы больше не обрезается квадратом по краям холста.
- «Рынок»: при быстрой смене монеты график иногда оставался пустым до следующего автообновления — теперь новая загрузка отменяет старую.

## 0.5.0 — 21.11.2026

Первая полноценная версия в репозитории. Проект собран заново поверх Этапа 1.

### Добавлено
- **Мозг на выбор**: Claude (Anthropic), DeepSeek или любой OpenAI-совместимый сервис (OpenAI, OpenRouter, Groq…). Модель и адрес API настраиваются.
- **Голос**: распознавание речи с текстом «на лету», озвучка ответов, скорость речи, авто-отправка после фразы.
- **Управление телефоном голосом**: звонок контакту по имени («позвони маме»), SMS, открыть приложение, будильник, таймер, фонарик, громкость, поиск, маршрут. Звонки и SMS — только после подтверждения.
- Команды разбираются прямо на телефоне (без интернета); сложные просьбы понимает ИИ и сам предлагает действие.
- **Рынок (Binance)**: свечной график (свайп — история, касание — перекрестие с OHLC), SMA 20/50, объём, RSI 14, автообновление каждые 10 с, таймфреймы 15м–1н.
- **ИИ-разбор рынка**: тренд, уровни, RSI/MACD, два сценария с уровнями входа/цели/стопа, риски.
- **Сделки**: рыночные ордера на сумму в USDT, баланс счёта. **Каждый ордер — только после подтверждения.** По умолчанию тестовая биржа (testnet), реальный счёт включается отдельно и подсвечивается.
- Голосом: «купи биткоин на 20 долларов», «график эфира».
- **Новый дизайн «Обсидиан и угли»**: живая сфера-ядро на GPU-шейдере (Android 13+), плёночное зерно, поле точек, шрифты Geist / Cormorant / Doto, новая иконка.
- История чата сохраняется между запусками (последние 300 сообщений).
- API-ключи шифруются ключом из Android Keystore.
- Автосборка APK на GitHub: каждая сборка появляется в разделе **Releases**.
- Юнит-тесты: разбор команд, индикаторы, подпись запросов Binance.

### Изменено
- Чат: ответы Архангела — как текст в журнале, а не «пузыри»; служебные сообщения отмечены точкой.
- Нижняя навигация: Ядро · Диалог · Рынок · Настройки.
- Постоянный debug-ключ подписи: новые версии ставятся поверх старых без удаления.

### Удалено
- Неоновая сине-бирюзовая тема Этапа 1 и тестовый эхо-режим.
